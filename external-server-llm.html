外部サーバ設定

次のどれを入れてもOKです。上から順に使い、失敗したら次のSpaceへ逃がします。
・SpaceページのURL https://huggingface.co/spaces/ユーザー名/Space名
・短縮形 ユーザー名/Space名
・直接URL https://ユーザー名-space名.hf.space
このURLをKindleのブラウザで開くと、Space設定が入った状態で始まります（合言葉は含みません）。

チャピ子設定

うまくいかない時
1. 「接続テスト」で各Spaceの状態を見る
2. 「接続できません」→ Spaceがスリープ中・ビルド中・URL間違い。「起こす」を押して待つか、Spaceページを開く
3. 「モデル読み込み中」→ 起動直後です。「起こす」で準備OKまで待つ
4. 無料CPUは遅いです。1回答に数十秒かかります
